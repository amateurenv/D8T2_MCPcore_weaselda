# Паспорт Лавки

Профиль правил: base

## Что делает сервер

Сервер предоставляет семь MCP-инструментов: чтение каталога, отдельного товара,
баланса и состояния заказа, а также создание, отмену и выдачу заказа. Создание
заказа списывает коины и уменьшает остаток; отмена возвращает их один раз;
выдача меняет только состояние заказа.

## Границы

Сервер работает только с пользователями из учебной базы и не проверяет личность
вызывающего. Клиенту нельзя обещать создание пользователя, пополнение баланса,
оплату деньгами, доставку или изменение каталога. Ожидаемые отказы возвращаются
кодами ошибок, а не исключениями Python.

## Путь запроса

`client.py` → `get_product` в `build_mcp_server()` из `src/mcp_adapter.py` →
`read_handlers.get_product()` → `Storage.get_product()` → `success(...)` или
`failure("PRODUCT_NOT_FOUND", ...)`.
