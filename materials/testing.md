# Как проверять сервер

Тест — код с входными данными и проверкой ожидаемого результата. В `testing/test_example.py` есть пример на готовом инструменте: он создаёт временную базу и проверяет возвращённый товар. Запуск:

~~~bash
python3 -m pytest -q
~~~

Пример проверки правила стоимости после его реализации:

~~~python
from src.domain import calculate_total

def test_two_bottles_cost_300():
    assert calculate_total(150, 2) == 300
~~~

Если функция вернула другое число, assert остановит тест и pytest покажет, какое ожидание нарушено. Сохраните такой код в файле с именем, начинающимся на test_.

Добавьте свои тесты. Выберите минимум три содержательных случая: правильный расчёт стоимости; отказ в покупке с неизменным состоянием; повторное действие с заказом. Это минимальная помощь в разработке, а не гарантия полноты. Отдельный тест нового условия понадобится для конверта.

Для отказа сначала сохраните состояние таблиц, выполните запрос и сравните состояние после него. Один правильный код ошибки недостаточен: сервер мог успеть списать коины.

## Общая проверка

~~~bash
python3 checks/acceptance.py --project . --profile base
~~~

Она запускает настоящий MCP-сервер отдельным процессом, использует собственные учебные данные во временной папке, проверяет перечень инструментов, схемы, покупки, отмены, выдачу, ошибки и состояние базы после отказов и перезапуска. Ваша рабочая база не участвует.

Для конверта замените `base` на `E1`, `E2`, `E3`, `E4` или `E5`. Профиль меняет ожидаемый результат только там, где изменилось условие. Номер в команде сам по себе не меняет поведение сервера.

Проверки открыты: их можно читать. Исправлять готовые проверки, чтобы принять неверное поведение, нельзя. На приёмке используется исходная копия проверяющего.

Если запуск с профилем конверта не проходит, допишите изменение или верните код к базовым правилам и сдайте `base`. Отразите это в `docs/change.md`.

Проверки не являются защитой от намеренно враждебного Python-кода. Они помогают обнаружить ошибки, а объяснение команды помогает понять её решение.
